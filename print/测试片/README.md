# 测试片图例（先打这个！）

> 复刻全机 237 个 M2 孔位和 14 个轴承座之前，先用这 3 个小件定标**你这台打印机**的实际公差。
> 总打印时间约 40 分钟，耗材约 15g。生成脚本：`scripts/generate_test_coupon.py`（尺寸可改后重新生成）。

## 1. `测试片-M2孔径阶梯-78x46x4.stl`

三行孔，每行从左到右 4 个（x = 12 / 30 / 48 / 66 mm）：

| 行（y 坐标） | 从左到右 | 判定方法 |
|---|---|---|
| 上行 y=36 | **M2 过孔阶梯 Ø2.2 / Ø2.3 / Ø2.4 / Ø2.5** | M2 螺丝手指能顺畅穿过、不晃 → 最小的那个就是你机器的过孔补偿值 |
| 中行 y=24 | **攻丝底孔阶梯 Ø1.60 / 1.65 / 1.70 / 1.75** | M2 自攻拧入 ≥3 圈不裂不旷 → 那个值就是攻丝底孔补偿 |
| 下行 y=12 | 参考 Ø4.4（沉头径）/ Ø3.0 / Ø2.7（M2.5 底孔）/ Ø2.2 | 对照用 |

## 2. `测试块-轴承22x16x4压入三档-76x26x4.stl`

Ø21.9 / Ø22.0 / Ø22.1 三孔（左→右）。把 **22×16×4 轴承**（11 个/机）逐个试压：

- **轻压入、拔不出来** = 过盈档 ✓（理想）
- 手指能压进去也抠出来 = 间隙档（太松，点胶固定用）
- 压进去开裂 = 过盈过头

## 3. `测试块-轴承15x10x3压入三档-55x18x4.stl`

Ø14.9 / Ø15.0 / Ø15.1 三孔，试 **15×10×3 轴承**（3 个/机），判定同上。

## 打印参数（就这次，别用高速）

PLA、0.2mm 层高、100% 填充、壁 3 圈、**速度 ≤100mm/s**、关闭"水平孔补偿"先打一版原始值。

## 测完之后

把两个"刚好"值填进 [构建日志](../构建日志.md) 的「尺寸与配合验证」表，
然后按 [打印工艺调整表](../docs/打印工艺调整表.md) 的补偿建议设置切片器，再开始批量打印。
