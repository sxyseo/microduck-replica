# Microduck 中分发型帽（试配版）

依据参考图重新塑形的一体式 3D 打印发型：左右两片厚刘海从头顶中分处垂到眼睛两侧，顶面有收尖的分缝，侧面有弧形分束和后发片，后脑由连续的中空帽壳覆盖。它套在仓库提供的固定头部上壳外，前方露出眼睛和面部，下缘抬到鸭嘴铰接区域上方。

## 文件

- [`中分发型帽.stl`](中分发型帽.stl)：单位为毫米的单件封闭网格，可导入切片软件。
- [`中分发型帽-preview.png`](中分发型帽-preview.png)：与原头壳、面部、眼圈和静态下巴叠放的正面、侧面预览。颜色只用于区分零件。
- [`中分发型帽-斜视图.png`](中分发型帽-斜视图.png)：同一装配体的斜视角预览。
- [`generate_hairstyle_cap.py`](generate_hairstyle_cap.py)：根据原版上头壳 STL 重建发型；可修改内侧净空、外侧厚度和最低下缘高度。

## 已检查的几何尺寸

| 项目              |                  当前 STL |
| --------------- | ----------------------: |
| 外包尺寸（X × Y × Z） | 101.4 × 133.8 × 32.9 mm |
| 发型最低点           |            Z = 22.09 mm |
| 原版静态下巴最高点       |            Z = 16.50 mm |
| 静态垂直间隙          |                 5.59 mm |
| 设计内侧净空          |         1.5 mm，基于上头壳的凸包 |
| 基础发片外凸量         |     5 mm；正面发片局部另增至 7 mm |

生成时检查网格为单件封闭实体，并用 0.35 mm 体素对原上下头壳、面部、眼圈、软嘴、静态下巴和电机支架的顶点与三角面中心进行干涉检查，当前结果均无重叠。上游 MJCF 中鸭嘴是固定网格，没有给出嘴部舵机与两侧连杆的全行程模型；**静态检查不能保证实物开合净空**。装到机器人前，应先断电手动转动嘴巴完成全行程，观察侧面连接处和下缘；出现擦碰就停止使用并增大下缘高度。当前版本也尚未实物试装。

## 打印与安装

建议先用 0.2 mm 层高、3 圈壁和 15–20% 填充打印试件。开口朝下切片，确认内顶面的支撑可取出；外表面避免支撑痕。当前模型没有卡扣或螺丝固定结构，可在**固定上头壳**的接触高点试用约 1–1.5 mm 的可移除泡棉双面胶，避开眼圈、鸭嘴及侧面连杆。胶带位置与厚度需要依照实际打印公差试配。

重建文件需要 Python 3 与 `numpy`、`scipy`、`scikit-image`、`trimesh`、`Pillow`：

```sh
python3 -m pip install numpy scipy scikit-image trimesh Pillow
python3 generate_hairstyle_cap.py
```

这是基于仓库上头壳网格制作的外观衍生件，沿用父目录项目的许可与署名要求。
