# 打印工艺调整表（FDM 适配）

> 配套：[打印就绪检查](打印就绪检查.md)（几何体检结论：30 种 / 41 件**全部水密、法向一致，可直接切片**）。
> 本表回答的是下一个问题：**几何能切 ≠ 装得起来**。仿真件没有配合公差，孔径是设计值，
> FDM 实际打印孔会缩小。这里给出每类孔的处理办法和一份「先打它」的测试片方案。

## 状态标签

- `【已验证】`：来自 `docs/hole_analysis.json` 的 STL 反推数据 + 本仓库已打印试装经验（构建日志：M2 螺丝已实际装入腿部件，孔位可用）
- `【推测】`：FDM 工艺经验值，**必须用测试片在你的打印机上实测校准**后才是你自己的数据

## 一、三类 M2 孔的处理（全机总量见体检报告：过孔 ×111、沉头 ×48、攻丝 ×27）

| 孔型 | 设计值 | 打印后趋势 | 处理办法 |
|---|---|---|---|
| **过孔**（螺丝穿过） | Ø2.2 | 缩小 0.1–0.3mm → M2 柱头螺丝装不进 | ① 首选切片器开「水平孔补偿 +0.15~0.25mm」；② 或打印后用 **Ø2.5 钻头**过一下。构建日志已验证：腿部件孔位反推正确，但**个别孔仍需钻孔修正**（正常现象） |
| **沉头孔**（M2 柱头/沉头沉入） | Ø4.4 | 直径缩小影响不大，深度基本不受影响 | 一般免处理；装不进时用 Ø4.5 钻头扩沉孔口即可 |
| **攻丝底孔**（螺丝直接拧进塑料） | Ø1.6 | 缩小 → 丝锥拧不进或滑丝 | PLA 建议底孔实值 **Ø1.65–1.75**：打印时补偿 +0.05~0.1，或打印后用 Ø1.65 钻头预钻再拧 M2 自攻（本项目为塑料自攻，不是金属丝锥） |

> ⚠️ 打印收缩还会受材料影响：PLA 收缩小、PETG 略大、ABS 最大。**换材料 = 重测补偿值。**

## 二、先打这个：孔径测试片（30 分钟出结论，全机孔位都靠它定补偿值）

打一张 60×40×4mm 测试片，包含：

```text
过孔阶梯   Ø2.2 / Ø2.3 / Ø2.4 / Ø2.5   ← 找出 M2 螺丝「刚好能过」的打印值
攻丝阶梯   Ø1.6 / Ø1.65 / Ø1.7 / Ø1.75 ← 找出自攻「拧得进且不裂」的打印值
沉头一对   Ø4.4 沉头 + Ø2.2 过孔组合    ← 验证柱头能沉平
轴承孔     Ø21.9 / Ø22.0 / Ø22.1       ← 轴承 22×16×4 的压入配合（过盈/过渡/间隙三档）
小轴承孔   Ø14.9 / Ø15.0 / Ø15.1       ← 轴承 15×10×3
```

判定：螺丝以手指力量能顺畅通过 = 合格过孔；自攻拧入 3 圈以上不裂不旷 = 合格底孔。
**把实测补偿值写进 [构建日志](../构建日志.md) 的「尺寸与配合验证」表** —— 这是整个复刻里最值钱的一行数据。

## 三、轴承座孔（精度敏感，单独对待）

| 部位 | 尺寸 | 建议 |
|---|---|---|
| 躯干/腿部轴承座 | Ø22 H7 级（22×16×4 轴承） | 用测试片定档。目标「轻压入」：多数 FDM 打 Ø21.9–22.0 + 砂纸修。太松用微量胶固定 |
| 头颈轴承座 | Ø15（15×10×3 轴承） | 同上，Ø14.9–15.0 起试 |

## 四、摆放与支撑（每件通用）

- **竖直孔**（轴向平行打印平面）无需支撑但会椭圆化（第一层/末层桥接）——过孔类尽量**孔轴垂直于打印平面**摆放，牺牲强度换装配
- 壳体类（头壳/左右壳 20970 面）大平面朝上，边缘裙边防翘曲
- 薄板件（上腿加固板 1.0mm 薄、颈部 2.0mm）注意**冷却风扇全开 + 减速**，防薄壁抖纹；加固板建议立印或加裙板
- 全部件用**同一台机器同一材料同一层高**打 —— 别让补偿值跨机器失效

## 五、整机用耗材估算（逐件体积 × 数量加权实测）

结构件 **241 cm³ ≈ 299 g PLA**（密度 1.24），软性件（软下巴/软嘴）**21.3 cm³ ≈ 26 g TPU**（密度 1.21）。
加损耗与失败件备一卷 1kg PLA 足够；TPU 买 500g 卷（用不到 1/10，留作轮滑胎）。
各件体积见 [打印就绪检查](打印就绪检查.md) 明细列（头壳最贵：上壳 29.9 + 下壳 23.8 cm³）。
