# 阶梯式采购与验证路线（主控缺货时期的执行策略）

> 背景：Radxa Zero 3W 缺货、淘宝溢价 3–6 倍；手头有树莓派。
> 问题：一次买齐 vs 分步买分步验证？**结论：分步——但要"门控式分步"**：
> 每一笔钱都由上一阶段的验证结果解锁，同时**长货期件在门控通过后立即下单**（让货期与调试并行）。
>
> 阶梯总投入（到舵机大单之前）≈ **¥350–450**——这是"知道自己在做什么"的成本，占总预算 <12%。

## 为什么分步赢

| | 一次买齐 | 阶梯式 |
|---|---|---|
| 舵机 ¥2580 的风险 | 打印/电路任何环节翻车，15 只舵机闲置 | 过 3 道门控才买，翻车损失上限 ¥450 |
| 主控缺货 | 卡死整机 | 树莓派顶上验证全流程，Radxa 到货/降价随时切换（官方路线零移植） |
| 试错信息 | 全部问题堆在总装时爆发 | 每层问题在它最便宜的阶段暴露 |
| 适合谁 | 有经验、供应链熟的人 | **初学者 + 缺货期 = 分步是唯一理性解** |

唯一反例：**长货期件不能等阶梯走完再买**——舵机国际渠道 1–3 周，门控通过后必须立刻下单，让物流时间与后续调试重叠。

## 阶梯（每阶段 = 采购清单 + 动作 + 通过门控）

### 阶段 0 · 本地仿真链路 —— ✅ 已完成（¥0）

训练/回放/对比/扰动/3D 捕获/操作台全部跑通（见 rl-series）。expC 续训正在进行。

### 阶段 1 · 打印定标 —— 采购 ≈¥5–10，随后 ¥99+¥30

- **买**：测试片打印（¥99 店，¥5–10）；TPU 两件另找渠道（¥30–50）
- **做**：卡尺量测试片 → 补偿值回填构建日志 → 全机 41 件 PLA 单（¥99）
- **门控 G1**：测试片孔径公差 ±0.2mm 内 + ≥90% 打印件完成 + 腿部件试装（此前已验证过孔位可用）
- **不达标怎么办**：调补偿重打测试片；公差件（轴承座）转嘉立创

### 阶段 2 · 电控最小闭环（树莓派 + 1 只舵机）—— 采购 ≈¥250

- **买**：FE-URT-1 调试板 ¥45、舵机线 ¥10、**第一只舵机**（XL330 ¥172 international 单买，或新舵机样品——这一只同时就是"换舵机路线"的判决实验品）、可调电源或 UBEC+电池 ¥50 估
- **做**（树莓派当地面调试台，零移植）：
  1. Pi 开启 UART（Pi 4 的 PL011 最佳；Pi 3 需 dtoverlay 禁蓝牙换主 UART，mini-UART 有抖动）
  2. rustypot / Dynamixel 工具：PING → 写读位置 → 1Mbps 收发 1000 包误包率
  3. **50Hz 连续控制环跑 10 分钟**（读状态 → 下位置指令）
- **门控 G2**：**单舵机在树莓派上 50Hz × 10 分钟零误包、位置无漂移**
  —— 这一关直接回答"树莓派能不能顶主控"，且换舵机路线的协议验证同时完成

### 阶段 3 · 自制板验证 —— 采购 ≈¥100–150

- **买**：`imu_to_dxl` 打样 ¥25–40 + 元件样品（BOM 14 种，各 1–2 片）¥30–60；同时嘉立创顺手把 HAT Gerber 打样（若走音频路线，¥100 级）或转接板+UBEC ¥47
- **做**：照[连接表](imu_to_dxl-设计包/原理图连接表.md)画板 → 贴片 → SWD 烧固件（协议层已 6/6 测试）→ 单板 PING / READ 124 → **接进阶段 2 的总线**
- **门控 G3**：**16 台设备（15 舵机 + IMU 板）同一次 sync_read 全部应答，30ms 预算内**
  —— 这验证的是官方运行时赖以工作的总线行为；在 Pi 上验证成立，换 Radxa 等价成立

### 阶段 4 · 舵机大单 + 整机机械 —— 采购 ≈¥2900–3300

- **解锁条件 = G1 ∧ G2 ∧ G3 全过**；此时下单：舵机 ×15（¥2580 起，1–3 周货期与后续调试重叠）、轴承、螺丝套装、热熔螺母+压头、乐泰
- **做**：批量打印收尾 → 躯干+腿装配（构建日志逐件记录）→ 全总线联调 → （可选）Pi 机载化移植或等 Radxa
- **门控 G4**：整机站立、全总线 10 分钟稳定、姿态可控

### 阶段 5 · 感知/音频/验收 —— 采购 ≈¥300–600

- **买**：摄像头 ¥33、ToF ¥70、（要音频才买）HAT SMT 数百或省略、喇叭
- **做**：装策略（官方 ONNX 若硬件同款 / 自训 ONNX 若换过舵机）→ L5 吊装 → L6 软垫 → L7 平地遥控，逐技能验收（清单见[换舵机重训全流程](换舵机重训全流程.md) §6）

## 树莓派的定位（明确说清）

1. **现在**：地面调试台——阶段 2/3 的全部验证都在它上面做，零移植；
2. **以后（可选）**：机载主控——官方 HAT 可插，但要移植 UART/i2c 设备树 + Rust 交叉编译，属"中型适配"；
   若 Radxa 恢复 ¥237 价位，**换回官方路线零移植**——两条路在 G3 之前完全共享，到 G4 才分叉，这就是把主控决策推迟到信息最充分的时点。
3. **注意**：Pi 4 最省心；Pi 3/Zero 的 mini-UART 有抖动，做 1Mbps 总线前先跑 dtoverlay 换 PL011。
