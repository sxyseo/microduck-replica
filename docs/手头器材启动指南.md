# 手头器材启动指南（现有装备能干什么、不能干什么）

> 你的库存：¥99 打印件（41 件 PLA）✅已到 · SG90 ×6 · 树莓派 Pi 2 Model B · 小智 ESP32 配件 · 树莓派扩展板
> 一句话结论：**能开始，今晚就能动手两件事**——但要分清"这些器材能验证什么、不能验证什么"。

## 一、先泼冷水：SG90 不能用于这只鸭子，但能教你最重要的一课

| | SG90 | Microduck 需要的（XL330 级） |
|---|---|---|
| 控制方式 | **PWM 脉宽**（每只要一路独立信号线，开环） | **串行总线**（一根线挂 15 只，带反馈） |
| 位置反馈 | ❌ 无（不知道自己在哪） | ✅ 12 位编码器实时回读 |
| 力矩 | ≈0.18 N·m（塑料齿轮易扫齿） | 0.52 N·m（还要超压到 0.6+） |
| 数量 | 你有 6 只 | 需 15 只 |

所以：**SG90 装不进这只鸭子**（安装孔位不同、力矩撑不起双足、没有反馈意味着 61 维观测里的关节位置/速度全是假的）。它也**替代不了阶梯 G2**——G2 验证的是总线协议，SG90 没有。

**但 SG90 + 树莓派是完美的 PWM 入门台架**，一晚上能学会四件事（这四件事决定了你后面接线、供电、调试的手感）：

1. 单舵机脉宽控制（500–2500µs ↔ 0–180°）；
2. **供电预算**：6 只 SG90 堵转可瞬间拉 4A+——**绝不能从树莓派 5V 取电**（会重启/烧），必须独立 5V≥3A 电源共地；
3. **开环的宿命**（关键一课）：带载后命令 90° 实际可能停在 80°，而你**无从得知**——这就是这只鸭子必须用带编码器的总线舵机的根本原因。亲眼见过，比读十遍文档都懂；
4. 多舵机协同序列（简易"动作组"编程）。

**跑法**：把 `rl-series/scripts/pi_sg90_bench.py` 拷到树莓派上（`scp` 或 U 盘），`python3 pi_sg90_bench.py`（用系统自带的 gpiozero；信号线接 GPIO 17/27/22/23/24/25，舵机红→外接5V，棕/黑→与树莓派**共地**）。

## 二、¥99 打印件到手 → 立刻做"收货实测"（阶段 1 的 G1 数据）

测试片没单独打没关系——**直接量成品更好**（这是真实交付物）：

1. **M2 过孔**：拿 M2×6 螺丝逐件试穿腿部件的孔——能顺畅穿过 = 公差合格；穿不过的记下是哪件哪个孔（后续钻 Ø2.5 修）；
2. **轴承座**：Ø22/Ø15 轴承（[¥5 那个链接](https://item.taobao.com/item.htm?id=670727787832)，14 个 ¥40）到了试压入——轻压不裂 = 合格；
3. **目检**：层纹方向、孔的椭圆度、明显欠挤出；
4. 全部记录进[构建日志](../构建日志.md)「尺寸与配合验证」表。

## 三、树莓派 Pi 2 Model B——定位与两个用法

- **现在（地面调试台）**：Pi 2 的主 UART 是完整的 PL011（没有 Pi 3/Zero 的 mini-UART 抖动问题，做 1Mbps 总线反而省事）。等总线舵机到手，接 3.3V 半双工适配电路即可跑 rustypot 做总线测试；
- **以后（可选机载化）**：官方 HAT 是 Pi 40-pin 板，Pi 2 能插，但要移植设备树/交叉编译，**G4 之后再决策**（或等 Radxa 降价换回零移植路线）；
- 注意：Pi 2 无自带 WiFi（调试期用网线即可）。

## 四、小智 ESP32 与扩展板——先入库，别分心

- **小智 ESP32**：那是 AI 语音聊天的硬件体系，与鸭子的控制栈无关。它日后有两个潜在用途：① ESP32 的 LEDC 有 16 路 PWM，可当**舵机控制协处理器**（Pi 发高层指令、ESP32 出 PWM——经典架构，正好对标官方"主控+协处理"的思路）；② 语音交互（鸭子本来就有喇叭/麦克风）。**现阶段封存**，别让它在关键路径上分心；
- **树莓派扩展板**：看型号——若是 PCA9685 类 **PWM 舵机帽**（16 路），正好接管 SG90 台架的供电与布线；若是 xiaozhi 语音板，归入上面 ESP32 条目。接线前发我看一眼最快。
