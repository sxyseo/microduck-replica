## 一、网络总表（Net List）

| 网络名 | 连接点 | 说明 |
|---|---|---|
| `BUS_V+` | J1.V+、J2.V+、U4.VIN | 总线电池正（6.6–8.4V，2S）【已验证】 |
| `GND` | J1.GND、J2.GND、J3.4(GND)、U1.VSS、U1.VSSA、U2.GND、U2.EP(若封装有)、U3.GND、U4.GND、C1–C7 的 GND 侧、R3.2、R6.2、LED2 阴极 | 公共地 |
| `+3V3` | U4.VOUT、U1.VDD、U1.VDDA、U2.VDD、U2.VDDIO、U2.CS、U3.VCC、C6/C7 另一侧、R1.1、R2.1、J3.1(3V3) | LDO 输出。**U2.CS 必须拉到 3V3 = I2C 模式**【核对：LSM6DSV16X 手册 §I2C/SPI 选择】 |
| `SCL` | U1.PB6、U2.SCL、R1.2 | I2C1 时钟，400kHz |
| `SDA` | U1.PB7、U2.SDA、R2.2 | I2C1 数据 |
| `DXL_DATA` | J1.DATA、J2.DATA、U3.Y、R4.1 | **总线数据线**（半双工单线）【已验证】 |
| `RX_FROM_BUS` | R4.2、U1.PA10 | DATA 串 100Ω 进 RX |
| `TX_TO_BUF` | U1.PA9、U3.A | TX 进缓冲器输入 |
| `OE_DIR` | U1.PA8、U3.OE、R3.1 | 发送方向控制；**R3 10k 下拉 = 上电默认断开**【设计】 |
| `IMU_INT1` | U2.INT1、U1.PA0 | 数据就绪中断（固件骨架先用轮询，预留） |
| `SWDIO` | U1.PA13、J3.2 | 调试 |
| `SWCLK` | U1.PA14、J3.3 | 调试 |
| `LED_HEART` | U1.PA7、R5.1 | 心跳/异常指示（R5=1k，LED 阳极←R5，阴极→GND） |
| `BOOT0_PD` | U1.PB8-BOOT0、R6.1 | R6 10k 下拉，确保正常启动模式【核对：G0 系列 BOOT0/选项字节默认值】 |

## 二、元件引脚预算（每个脚都有去处，防漏连）

### U1 · STM32G031F8P6（TSSOP-20）

| 引脚（名） | 去 向 |
|---|---|
| PA0 | `IMU_INT1` |
| PA7 | `LED_HEART` |
| PA8 | `OE_DIR` |
| PA9 (USART1_TX) | `TX_TO_BUF` |
| PA10 (USART1_RX) | `RX_FROM_BUS` |
| PA13 (SWDIO) | `SWDIO` |
| PA14 (SWCLK) | `SWCLK` |
| PB6 (I2C1_SCL) | `SCL` |
| PB7 (I2C1_SDA) | `SDA` |
| PB8 (BOOT0) | `BOOT0_PD` |
| VDD / VDDA | `+3V3` |
| VSS / VSSA | `GND` |
| 其余 PA/PB 引脚 | NC（可引测试点）【核对：20 脚封装实际存在的引脚集以数据手册为准】 |

### U2 · LSM6DSV16X（LGA-14）

| 引脚 | 去 向 |
|---|---|
| VDD、VDDIO | `+3V3` |
| GND（含散热焊盘 EP） | `GND` |
| SCL / SDA | `SCL` / `SDA` |
| CS | `+3V3`（**I2C 使能，勿悬空**） |
| INT1 | `IMU_INT1` |
| SA0 | `GND`（I2C 地址 = 0x6A） |
| INT2 / 其余 | NC |

### U3 · SN74LVC1G126（SC-70-5）

| 引脚 | 去 向 |
|---|---|
| VCC / GND | `+3V3` / `GND` |
| A | `TX_TO_BUF` |
| Y | `DXL_DATA` |
| OE | `OE_DIR` |

### U4 · HT7533-1（SOT-89）／ J1 J2 · JST-EH-3P ／ J3 · SWD 1×4

| 元件 | 连接 |
|---|---|
| U4 | VIN=`BUS_V+`，VOUT=`+3V3`，GND=`GND`；C6(10µF ≥25V) 挂 VIN，C7(10µF) 挂 VOUT |
| J1 / J2（入/出菊花链） | 1=`BUS_V+`，2=`GND`，3=`DXL_DATA`（JST-EH 2.5mm，**与官方 HAT 同料号 C160259**） |
| J3（SWD 1×4） | 1=`+3V3`，2=`SWDIO`，3=`SWCLK`，4=`GND` |

### 阻容归位

| 位号 | 值 | 一侧 | 另一侧 |
|---|---|---|---|
| C1/C2/C3 | 100nF | U1.VDD / U2.VDD / U3.VCC | GND（就近） |
| C4/C5 | 100nF | U1.VDDA / U2.VDDIO | GND |
| C6 | 10µF **≥25V 0805** | `BUS_V+` | GND（**耐压是踩坑修正，勿用 10V**） |
| C7 | 10µF 0603 | `+3V3` | GND |
| R1/R2 | 4.7k | `+3V3` | `SCL`/`SDA` |
| R3 | 10k | `OE_DIR` | GND |
| R4 | 100Ω | `DXL_DATA` | `RX_FROM_BUS` |
| R5 | 1k | `LED_HEART` | LED 阳极 |
| R6 | 10k | PB8-BOOT0 | GND |

## 三、画图自查清单

- [ ] 每个网络标签拼写与上表逐字一致（EDA 按名字连，拼写错 = 断网）
- [ ] U2.CS 已拉 `+3V3`（悬空 = 进 SPI 模式，I2C 读不到，最常见翻车点）
- [ ] C6 耐压 ≥25V（挂 8.4V 总线，10V 件会长期超压）
- [ ] U3.OE 有 R3 下拉（上电默认断开总线，防抢线）
- [ ] J1/J2 连接器引脚顺序与 JST-EH 丝印一致（V+ / GND / DATA）
- [ ] DRC 无悬空引脚（NC 项在符号上标记为 NC）
