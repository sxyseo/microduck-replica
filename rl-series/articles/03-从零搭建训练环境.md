# 03 · 从零搭建训练环境：两条真实的坑

> 状态：**可发布**
> 事实状态：全部 `【已验证】`（Mac mini / Apple Silicon / Python 3.12 venv 实跑）

> 骨架：我改了什么（无，纯搭建）→ 怎么运行 → 踩了什么坑 → 怎么验证搭好了

## 搭建三步

```bash
git clone https://github.com/pollen-robotics/microduck_rl
cd microduck_rl
uv sync                 # 创建 .venv 并装好全部依赖（含 mujoco、rsl_rl、tensorboard）
```

uv 会把一切隔离在 `.venv` 里，不污染系统 Python。装完之后仓库自带三个命令行入口（这是 mjlab 框架的约定）：

```bash
uv run list-envs        # 列出所有注册的任务
uv run train <任务ID> --env.scene.num-envs 64 --agent.max_iterations 5   # 冒烟测试
uv run tensorboard --logdir logs/rsl_rl
```

注意 `max_iterations` 是**下划线**——官方 AGENTS.md 这么写，照抄就好（我第一次写成连字符，参数没生效，训练跑完才看出来）。

## 怎么验证搭好了：list-envs

`uv run list-envs` 跑通就说明依赖、注册机制全链路 OK。真实输出（节选，完整版 53 行）：

```
[mdp] Patches 1-2 active: NaN-safe reward/advantage
[mdp] Patch 4 active: ONNX export filters passive_* joints
+---------------------------------------------------------+
|             Available Environments in mjlab             |
+----+----------------------------------------------------+
| 1  | Mjlab-BallKick-Flat-Backlash-MicroDuck             |
| ...
| 36 | Mjlab-Velocity-Flat-MicroDuck                      |
| 38 | Mjlab-Velocity-Flat-Unitree-G1                     |
+----+---------------------------------------------------------+
```

前两行的 `Patches active` 是这个仓库的 monkey-patch 声明——它运行时给 rsl_rl 打了 NaN 安全补丁、给 ONNX 导出打了被动关节过滤补丁。这也是「配置不等于行为」的一个例子，后面讲 reward 时会回来。

顺带你能看出注册了 30 多个 MicroDuck 任务：走路、踢球、捡东西、站起来、轮滑模式……还有个 Unitree G1（人形机器人）。这些名字全部来自我们下一阶段要读的 `tasks/__init__.py`。

## 坑一：`timeout` 命令 macOS 没有

我给训练命令套了 Linux 习惯的 `timeout 120 ...`，zsh 直接 `command not found`。macOS 上用 `gtimeout`（coreutils）或者干脆不用。小事，但第一次搭环境的挫败感都是这种小事攒的。

## 坑二：想渲染鸭子看看，结果两连黑

用 MuJoCo 加载官方 MJCF 想出一张封面图（脚本在 `rl-series/scripts/render_duck.py`），接连报错：

1. `Image width 1440 > framebuffer width 640`——MJCF 里离屏缓冲默认 640 宽。解法：加载后改 `model.vis.global_.offwidth = 1440`。
2. 渲染出来了，但整帧近黑——**这个模型没定义灯光**。解法：往 XML 的 `<worldbody>` 里注入一盏平行光。

```python
model = mujoco.MjModel.from_xml_path(tmp)
model.vis.global_.offwidth = 1440
model.vis.global_.offheight = 1080
# 往 worldbody 注入：<light directional="true" ... ambient="0.25 0.25 0.25"/>
```

成品就是本系列封面那只鸭子（`assets/duck-render-03-四分之三.png`）。

## 训练到底要什么显卡？

【已验证】5 迭代 × 8 环境的冒烟测试，Mac mini 纯 CPU 几分钟就完事，本机完全够用。【推测，待验证】官方 README 的正式训练是 `--env.scene.num-envs 4096` + 数万迭代，这个规模必须 GPU（走 MJWarp 并行）；没有卡可以用官方内置的 `--hf-jobs` 把训练丢到 HuggingFace Jobs 上跑。我第 3 周会实测并出对比数据（文章 09）。
